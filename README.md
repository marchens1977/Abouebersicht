# ⚾ Abo-Übersicht

Alle Abos und ihre Kosten im Blick – als Android-App in Orange & Blau.

<img src="www/icons/icon-192.png" width="96" alt="Logo">

**📲 App herunterladen:** [Abo-Uebersicht.apk](https://github.com/marchens1977/Abouebersicht/releases/latest/download/Abo-Uebersicht.apk)

- Kosten pro Tag, Woche, Monat und Jahr
- Reiter je Kategorie (KI, Streaming, Musik, Software, Gaming …)
- Abos automatisch im Kontoauszug finden – PDF oder CSV, wird nur auf dem Handy gelesen und nie gespeichert oder hochgeladen
- Verlauf bei Preis- oder Tarifwechsel (z. B. kostenlos → bezahlt)
- Erinnerung vor Abbuchungen und vor Ende einer Testphase
- „Was wäre, wenn …?“-Sparrechner
